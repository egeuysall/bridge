# Publish Markdown notes with Bri

Bri is an **open-source publishing platform** for Markdown notes, private drafts, and quick links. Use the web app when you want a dashboard, or use the CLI and API when you want repeatable workflows.

## The core model

- **Notes** hold Markdown content with a title, slug, visibility, and optional expiration.
- **API keys** are scoped as `read`, `write`, or `read_write` and can be revoked from the dashboard.
- **Interfaces** share the same server-side permissions: the web app, REST API, CLI, and MCP server.
- **Links** provide short, trackable redirects alongside your notes.

## One endpoint, several clients

The canonical **write endpoint** is `https://bri.fyi/api/notes`. The CLI and MCP server use it for publishing, while public readers can use a note URL or the JSON and Markdown read endpoints.

<Check>
**No vendor lock-in:** Bri stores your content as Markdown, exposes a documented HTTP API, and keeps the CLI configuration in `~/.config/bri/config.json`.
</Check>
